# Developer Docs Glossary

## Developer Documentary

The repo's developer-facing knowledge lane for verified understanding of live code.

## Code Index

A fast navigation map that points engineers to the right files before deep reading.

## Module Guide

A focused page describing what one subsystem owns, where it starts, and how it is organized.

## Flow Guide

A page that traces an end-to-end execution path through the codebase.

## Entrypoint

The file, function, route, handler, worker, or command where a subsystem or flow begins.

## Facade

A thin public surface that fronts more detailed or fragmented internal implementation.

## Contract

An expected behavior or interface between layers that other code relies on.

## Invariant

A condition that should remain true across edits, runs, and refactors.

## Extension Point

A place where new behavior can be added with relatively low risk to surrounding code.

## Footgun

A place where a change looks small but can easily cause regressions or confusion.
